# 三种分析场景的 Prompt 差异化需求分析

## 当前问题

所有三个功能都使用同一个 `SYSTEM_PROMPT`（在 analyzer.py 中定义），该 prompt 是为"持仓深度分析"设计的，包含：
- 决策仪表盘格式
- 买卖点位建议
- 持仓策略
- 详细的技术面分析

但三个场景的**分析目的完全不同**：

---

## 场景 1：选股推荐（Stock Selection）

### 分析目的
从大量候选股中筛选出**最值得关注的股票**

### 关键问题
- 为什么这只股票值得推荐？
- 与其他候选股相比的优势是什么？
- 现在是否是介入的好时机？
- 风险点在哪里？

### 应该关注
- ✅ 相对优势（vs 其他候选股）
- ✅ 介入时机（是否适合现在买入）
- ✅ 潜力空间（上涨预期）
- ✅ 风险可控性

### 不需要关注
- ❌ 具体买卖点位（用户还没决定是否买入）
- ❌ 持仓策略（用户还没持仓）
- ❌ 过于详细的技术分析（候选股太多）

### 建议 Prompt 重点
```
你是选股分析师，从候选池中筛选优质股票。

核心任务：
1. 评估该股票的投资价值（0-100分）
2. 说明推荐理由（为什么比其他股票更好）
3. 判断介入时机（现在是否合适）
4. 提示主要风险

输出要求：
- 简洁明了（候选股多，用户快速浏览）
- 突出亮点（吸引用户关注的理由）
- 风险透明（让用户知道可能的坑）
```

---

## 场景 2：调仓建议（Portfolio Adjustment）

### 分析目的
对**已持仓股票**给出仓位调整建议

### 关键问题
- 当前仓位是否合理？
- 应该加仓、减仓还是清仓？
- 调仓的紧迫性如何？
- 风险变化如何？

### 应该关注
- ✅ 趋势变化（相比建仓时的变化）
- ✅ 仓位合理性（当前仓位是高是低）
- ✅ 调仓时机（是否需要立即调整）
- ✅ 风险管控（止损、止盈）

### 不需要关注
- ❌ 是否值得买入（已经持仓了）
- ❌ 与其他股票对比（focus 在这只股票本身）

### 建议 Prompt 重点
```
你是持仓管理分析师，针对已持仓股票给出仓位调整建议。

核心任务：
1. 评估趋势变化（相比建仓时）
2. 判断仓位合理性（当前X%是否合适）
3. 给出调仓建议（加仓/减仓/清仓/持有）
4. 说明调仓理由和紧迫性

输出要求：
- 关注变化（趋势是变好还是变坏）
- 仓位导向（明确建议仓位百分比）
- 风控优先（止损、止盈位明确）
```

---

## 场景 3：持仓深度分析（Deep Analysis）

### 分析目的
对**自选股**进行全面深度分析，提供完整决策仪表盘

### 关键问题
- 全方位评估（技术面、基本面、消息面）
- 精确的买卖点位
- 详细的操作计划
- 完整的风险评估

### 应该关注
- ✅ 全面分析（不遗漏任何维度）
- ✅ 精确点位（买入、止损、止盈）
- ✅ 决策仪表盘（一站式决策信息）
- ✅ 行动清单（可执行的操作步骤）

### 当前 Prompt
✅ **已经很完善**，适合这个场景

---

## 优化建议

### 方案 A：在 analyzer.py 中新增两个 Prompt

```python
class GeminiAnalyzer:
    # 持仓深度分析（现有）
    SYSTEM_PROMPT_DEEP_ANALYSIS = """..."""
    
    # 选股推荐（新增）
    SYSTEM_PROMPT_STOCK_SELECTION = """
    你是选股分析师，评估候选股票的投资价值...
    """
    
    # 调仓建议（新增）
    SYSTEM_PROMPT_PORTFOLIO_ADJUSTMENT = """
    你是持仓管理分析师，评估仓位调整...
    """
    
    def analyze(self, context, news_context=None, mode="deep_analysis"):
        # 根据 mode 选择不同的 prompt
        if mode == "stock_selection":
            prompt = self.SYSTEM_PROMPT_STOCK_SELECTION
        elif mode == "portfolio_adjustment":
            prompt = self.SYSTEM_PROMPT_PORTFOLIO_ADJUSTMENT
        else:
            prompt = self.SYSTEM_PROMPT_DEEP_ANALYSIS
```

### 方案 B：创建专门的分析器类（更优）

```python
# 选股分析器
class StockSelectionAnalyzer(GeminiAnalyzer):
    SYSTEM_PROMPT = """选股专用 prompt..."""

# 调仓分析器
class PortfolioAdjustmentAnalyzer(GeminiAnalyzer):
    SYSTEM_PROMPT = """调仓专用 prompt..."""
```

## 实施优先级

### P0（高优先级）
- ✅ **选股 Prompt 差异化** - 影响推荐质量
- ✅ **调仓 Prompt 差异化** - 影响仓位建议准确性

### P1（中优先级）
- 优化输出格式（选股和调仓不需要完整的决策仪表盘）
- 精简分析内容（选股场景下减少详细分析）

### P2（低优先级）
- 性能优化（选股时可以并发分析）
- 缓存机制（避免重复分析同一只股票）

---

## 总结

**当前状态**：三个场景用同一个 prompt ❌

**应该做的**：
1. 为"选股推荐"设计专门的 prompt（重点：为什么推荐、介入时机）
2. 为"调仓建议"设计专门的 prompt（重点：仓位合理性、调仓方向）
3. 保持"深度分析"的详细 prompt（重点：全面决策信息）

**收益**：
- 提高分析准确性（针对性更强）
- 提升用户体验（信息更精准）
- 减少无用信息（选股不需要看完整决策仪表盘）
