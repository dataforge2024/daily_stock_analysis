# 📊 新功能配置说明 - 选股推荐 & 调仓建议

## 🎯 功能概述

系统新增两大核心功能：

1. **每日推荐股票** - 基于股票池智能选股（10～20只）
2. **智能调仓建议** - 优化持仓结构，动态调整仓位

## 📌 功能特点

### 1️⃣ 每日推荐股票

#### 功能说明
- 从配置的股票池（沪深300、中证500、创业板50等）筛选优质股票
- **两阶段智能选股**：规则筛选 + AI 深度分析
- 综合分析价格、量能、趋势、波动、市场拥挤度等维度
- 每日推荐10～20只具有投资潜力的股票
- **AI 提供详细理由、关键指标和风险提示**

#### 选股策略

**第一阶段：规则筛选（多因子模型）**

采用多因子量化选股模型，包括：

**技术面因子（权重 75%）**
- 趋势强度（25%）：MA5 > MA10 > MA20 多头排列
- 量能配合（20%）：量价配合、缩量回调
- 波动率（15%）：适度波动（5-15%年化）
- 乖离率（15%）：不追高（-2% ~ +5%）

**基本面因子（权重 25%）**
- 市值规模（10%）：流动性考量
- 换手率（5%）：资金活跃度
- 近期表现（10%）：短期动能

**第二阶段：AI 深度分析（默认启用）**
- 从规则筛选的候选股（Top 50）中进一步分析
- 调用 Gemini AI 分析每只候选股的完整技术面和行情数据
- 筛选 AI 评分 ≥ 60 的股票
- 综合排序：**AI 评分 70% + 规则评分 30%**
- 生成详细的投资理由、关键指标和风险提示

#### 配置方式

**方式一：GitHub Actions Secrets**

| Secret 名称 | 说明 | 示例 | 必填 |
|------------|------|------|:----:|
| `STOCK_POOLS` | 股票池列表（逗号分隔） | `沪深300,中证500` | ✅ |
| `RECOMMEND_MIN_STOCKS` | 最少推荐数量 | `10` | 否 |
| `RECOMMEND_MAX_STOCKS` | 最多推荐数量 | `20` | 否 |

**方式二：本地 .env 文件**

```bash
# 股票池配置（可选多个，逗号分隔）
# 可选项：沪深300、中证500、创业板50、科创50、上证50、中证1000
STOCK_POOLS=沪深300,中证500

# 推荐股票数量范围（可选，默认10～20）
RECOMMEND_MIN_STOCKS=10
RECOMMEND_MAX_STOCKS=20

# 是否启用推荐功能（可选，配置了STOCK_POOLS自动启用）
RECOMMEND_ENABLED=true
```

### 2️⃣ 智能调仓建议

#### 功能说明
- 基于现有持仓（STOCK_LIST）生成调仓建议
- **两阶段分析**：
  - 第一阶段：规则分析（技术指标、趋势信号）
  - 第二阶段：AI 深度分析（可选，默认启用）
- 结合个股技术面表现和 AI 智能分析
- 动态调整仓位比例（0～100%）
- 提供加仓、减仓、卖出、持有等明确建议
- **AI 分析会修正规则建议**，提供更准确的调仓理由

#### 调仓策略

**加仓条件**
- 趋势信号：强烈买入、买入
- 当前仓位：< 80%
- 建议操作：增至原来的 150%（上限100%）
- **AI 修正**：如果 AI 评分 ≤ 40，可能调整为减仓

**减仓条件**
- 趋势信号：观望
- 当前仓位：> 30%
- 建议操作：减至原来的 50%（下限30%）
- **AI 修正**：如果 AI 评分 ≥ 75，可能调整为持有

**卖出条件**
- 趋势信号：卖出、强烈卖出
- 建议操作：清仓（仓位归零）
- **AI 修正**：如果 AI 评分 ≥ 75，可能调整为持有

**持有条件**
- 趋势信号：持有
- 建议操作：保持当前仓位
- **AI 修正**：如果 AI 评分 ≤ 40，可能调整为减仓

#### 配置方式

**方式一：GitHub Actions Secrets**

| Secret 名称 | 说明 | 示例 | 必填 |
|------------|------|------|:----:|
| `STOCK_LIST` | 自选股列表（逗号分隔） | `600519,300750,002594` | ✅ |
| `POSITION_RATIOS` | 仓位比例（格式：代码:比例） | `600519:100,300750:80,002594:50` | 否 |

**方式二：本地 .env 文件**

```bash
# 自选股列表（必填）
STOCK_LIST=600519,300750,002594

# 仓位比例配置（可选，格式：股票代码:比例）
# 不配置则默认为100%
POSITION_RATIOS=600519:100,300750:80,002594:50

# 是否启用调仓建议（可选，配置了STOCK_LIST自动启用）
PORTFOLIO_ADVICE_ENABLED=true
```

## 📝 注意事项

1. **STOCK_LIST 不再必须**：如果只想获取推荐股票，可以不配置 STOCK_LIST
2. **股票池选择建议**：
   - 沪深300：大盘蓝筹，适合稳健投资
   - 中证500：中盘成长，兼顾收益与风险
   - 创业板50：科技成长，高风险高收益
   - 可同时配置多个股票池，系统会自动去重
3. **仓位比例说明**：
   - 取值范围：0～100（代表仓位百分比）
   - 不配置默认100%（满仓）
   - 建议根据个股风险特征设置不同仓位
4. **推送顺序**：
   - 推荐股票 → 个股分析 → 调仓建议 → 大盘复盘
   - 每个模块独立推送，互不影响
5. **数据量控制**：
   - 推荐股票选股过程会处理数百只股票，耗时较长
   - 建议在非交易时段运行（如18:00）
   - GitHub Actions 默认每天18:00自动运行

## 🎯 使用建议

### 推荐工作流程

1. **每日查看推荐股票**
   - 关注 AI 评分 ≥ 75 的股票
   - 重点阅读 AI 生成的理由和风险提示
   - 了解市场热点和优质标的
   - 作为建仓参考

2. **深度分析自选股**
   - 获取AI决策仪表盘
   - 明确买卖点位

3. **执行调仓建议**
   - 优先关注 AI 修正后的建议
   - AI 评分与规则建议冲突时，重点考虑 AI 建议
   - 优化持仓结构
   - 动态调整仓位

4. **参考大盘复盘**
   - 把握市场节奏
   - 调整投资策略

### 风险提示

- ⚠️ 本系统仅供参考，不构成投资建议
- ⚠️ 推荐股票基于量化模型和 AI 分析，需结合基本面判断
- ⚠️ **AI 分析可能存在偏差，不应作为唯一决策依据**
- ⚠️ 调仓建议仅供参考，具体操作需谨慎
- ⚠️ 投资有风险，决策需谨慎

## 🔧 故障排查

### 问题1：选股功能不运行

**检查清单**：
- ✅ 是否配置了 `STOCK_POOLS`
- ✅ 股票池名称是否正确（沪深300、中证500等）
- ✅ 网络是否正常（能否访问AkShare）
- ✅ **GEMINI_API_KEY 是否配置正确（AI 分析需要）**

### 问题2：AI 分析未生成

**检查清单**：
- ✅ GEMINI_API_KEY 是否有效
- ✅ Gemini API 配额是否用完
- ✅ 网络能否访问 Google AI API
- ✅ 查看日志中的 AI 分析错误信息

### 问题3：调仓建议不生成

**检查清单**：
- ✅ 是否配置了 `STOCK_LIST`
- ✅ 股票代码格式是否正确（如600519）
- ✅ 数据源是否正常

### 问题4：推送未收到

**检查清单**：
- ✅ 通知渠道是否正确配置
- ✅ Webhook URL 是否有效
- ✅ 查看日志中的错误信息
